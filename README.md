# Sudoku-Algorithms
this project contains different algorithms to solve Sudoku puzzles using Python.

## 🗂 Project Structure

- `BacktrackingAlorthim.py` – Basic backtracking algorithm.
- `BacktrackingWithHeuristic.py` – Backtracking with MRV, Forward Checking, and AC3.

## 🧠 Algorithms

### 1. Backtracking
A simple recursive method that tries every possible number in each empty cell.

### 2. Backtracking + Heuristics
Uses Minimum Remaining Values (MRV), Forward Checking, and AC3 for smarter search.
